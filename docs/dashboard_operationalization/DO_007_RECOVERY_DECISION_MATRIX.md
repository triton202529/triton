# DO-007 — Recovery Decision Matrix

## Classifications

| Classification | Severity | Typical safe action |
|----------------|----------|---------------------|
| HEALTHY | INFO | NO_ACTION_CONTINUE_MONITORING |
| FULLY_STOPPED | INFO | CONSIDER_PROTECTED_START (if DO-003 enables) |
| PARTIALLY_RUNNING | HIGH | CONSIDER_PROTECTED_RESTART or MANUAL_INVESTIGATION |
| STALE_OR_INCONSISTENT_LOCK_EVIDENCE | HIGH | MANUAL_INVESTIGATION_REQUIRED |
| UNVERIFIED_PROCESS_IDENTITY | CRITICAL | RECOVERY_ACTION_BLOCKED |
| STOP_IN_PROGRESS | MEDIUM | WAIT_FOR_ACTIVE_TRANSACTION |
| STOP_PARTIAL_OR_TIMED_OUT | HIGH | MANUAL_INVESTIGATION_REQUIRED |
| START_IN_PROGRESS | MEDIUM | WAIT_FOR_ACTIVE_TRANSACTION |
| START_PARTIAL_OR_TIMED_OUT | HIGH | MANUAL_INVESTIGATION_REQUIRED |
| RESTART_IN_PROGRESS | MEDIUM | WAIT_FOR_ACTIVE_TRANSACTION |
| RESTART_PARTIAL_OR_TIMED_OUT | HIGH | MANUAL_INVESTIGATION_REQUIRED |
| ACTIVE_CONTROL_TRANSACTION_CONFLICT | CRITICAL | RECOVERY_ACTION_BLOCKED |
| LIVE_EXECUTION_ENABLED_INCIDENT | CRITICAL | ESCALATE_TO_OPERATOR |
| INSUFFICIENT_EVIDENCE | HIGH | MANUAL_INVESTIGATION_REQUIRED |
| PAPER_AUTHORIZATION_MISSING | MEDIUM | reported as separate warning fact |
| LIVE_EXECUTION_BLOCKED | INFO | required safe state warning |

## Precedence (highest first)

1. ACTIVE_CONTROL_TRANSACTION_CONFLICT\
2. LIVE_EXECUTION_ENABLED_INCIDENT\
3. UNVERIFIED_PROCESS_IDENTITY\
4. STALE_OR_INCONSISTENT_LOCK_EVIDENCE\
5. INSUFFICIENT_EVIDENCE\
6. STOP_IN_PROGRESS / RESTART_IN_PROGRESS\
7. STOP_PARTIAL_OR_TIMED_OUT\
8. START_PARTIAL_OR_TIMED_OUT\
9. RESTART_PARTIAL_OR_TIMED_OUT\
10. START_IN_PROGRESS\
11. PARTIALLY_RUNNING\
12. FULLY_STOPPED\
13. HEALTHY\

Paper authorization and live-blocked status are separate safety facts and do not override identity concerns.
