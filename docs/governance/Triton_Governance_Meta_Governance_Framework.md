# Card 1 — Meta-Governance Philosophy

### Purpose of governance self-governance

Meta-governance ensures Triton’s control layer **improves without destabilizing**. It defines when governance may change, who may approve it, what evidence is required, and how learning becomes durable—without bureaucracy replacing judgment or novelty replacing containment.

### Why governance itself must be governed

| Ungoverned governance risk | Meta-governance outcome |
|----------------------------|-------------------------|
| Ad hoc manual edits | Versioned `GOVCHG` path |
| Safeguard erosion under pressure | Constitutional tier lock |
| Process bloat | Drift controls (Card 5) |
| Conflicting manuals | Step 100 supremacy + 98 register |
| “Improvement” without evidence | `GOVMETA` evidence gate |
| Oral policy drift | Written effective version only |

### Core principles

| Principle | Meta-governance meaning |
|-----------|-------------------------|
| **Capital Preservation Doctrine supremacy** | Evolution never trades containment for convenience |
| **Constitutional safeguards dominate** | Highest tier for safeguard changes |
| **Governance before governance change** | Classify before edit (Card 3) |
| **Evidence before evolution** | Weakness must be evidenced |
| **Containment before experimentation** | Drill before effective date (98) |
| **Institutional humility** | Failed changes and near-misses archived |
| **Disciplined adaptation** | Committee path for material change |
| **Continuity over novelty** | Prefer clarify over expand |

### What meta-governance proves

- Governance changes follow **classified approval** (Cards 3, 6)
- Self-improvement uses a **repeatable loop** (Card 4)
- **Drift and bureaucracy** are monitored (Card 5)
- Constitutional evolution is **rare, evidenced, reversible** (Card 6)
- Lessons from crisis, audit, war games feed **controlled** updates (Card 8)

### What meta-governance cannot guarantee

- Perfect governance forever
- Zero incidents after improvement
- That every proposal is adopted
- Automatic GHS/IRS improvement
- Permission to relax live controls via documentation
- Immunity from organizational resistance or fatigue

# Card 3 — Meta-Governance Change Classification

Five tiers. **All material+ changes** require `GOVCHG-*`; proposals may open as `GOVMETA-*` first.

---

### CLARIFICATION_CHANGE

| Field | Detail |
|-------|--------|
| **Definition** | Grammar, cross-links, examples—no authority/threshold change |
| **Risk level** | **Low** |
| **Approval requirement** | Governance Lead |
| **Escalation expectation** | None unless confusion reported |
| **Evidence requirement** | Diff; operator bulletin optional |
| **Rollback expectation** | Patch revert discretionary |

---

### PROCEDURAL_CHANGE

| Field | Detail |
|-------|--------|
| **Definition** | SOP/workflow within existing authority (90, 91, 102) |
| **Risk level** | **Low–Medium** |
| **Approval requirement** | Lead; Senior Operator review if operator-facing |
| **Escalation expectation** | Risk Lead if trading-window procedure |
| **Evidence requirement** | Rationale; affected playbooks listed |
| **Rollback expectation** | **5bd** revert if drill fail (95) |

---

### MATERIAL_GOVERNANCE_CHANGE

| Field | Detail |
|-------|--------|
| **Definition** | KPI bands, maturity gates, reporting fields, role matrix (non-constitutional) |
| **Risk level** | **Medium–High** |
| **Approval requirement** | Committee; dual approval if thresholds loosen |
| **Escalation expectation** | Executive if readiness/maturity impact |
| **Evidence requirement** | 90d data or incident cluster; training impact (97) |
| **Rollback expectation** | Mandatory if GHS −2 bands in 14d (98) |

---

### CONSTITUTIONAL_CHANGE

| Field | Detail |
|-------|--------|
| **Definition** | Safeguards, Hard Halt rules, dual approval, doctrine, Step 100 non-negotiables |
| **Risk level** | **Critical** |
| **Approval requirement** | Committee quorum + Executive; external counsel if legally material |
| **Escalation expectation** | Same-day Executive line |
| **Evidence requirement** | Incident/audit/war-game pack; drill pass before effective |
| **Rollback expectation** | **Mandatory** path pre-published; emergency rollback ≤1h invoke |

---

### META_GOVERNANCE_EMERGENCY

| Field | Detail |
|-------|--------|
| **Definition** | Active ambiguity threatening containment during live incident/crisis |
| **Risk level** | **Critical (time-bound)** |
| **Approval requirement** | Executive + Committee chair; full Committee **24h** |
| **Escalation expectation** | Immediate; sunset **≤72h** or formalize via CONSTITUTIONAL |
| **Evidence requirement** | Crisis link `GOVCRISIS-*` or L4 `INC-*` |
| **Rollback expectation** | **Mandatory** at sunset; containment default unchanged |

# Card 4 — Governance Self-Improvement Operating Model

```
Identify weakness → Collect evidence → Classify governance risk
→ Committee review → Approve / reject / defer
→ Controlled adoption → Review outcomes → Preserve lessons learned
```

---

### Identify weakness

| Field | Detail |
|-------|--------|
| **Purpose** | Start improvement cycle |
| **Required actions** | Open `GOVMETA-*`; source (audit, incident, KPI, drill, succession) |
| **What NOT to do** | Edit manuals before classification |
| **Escalation expectation** | Lead triage **5bd** |
| **Evidence expectation** | One-page problem statement |

---

### Collect evidence

| Field | Detail |
|-------|--------|
| **Purpose** | Prove need |
| **Required actions** | Link `INC-*`, `GOVAUDIT-*`, GHS, war-game, `GOVSUCC` as applicable |
| **What NOT to do** | Anecdote-only proposals |
| **Escalation expectation** | Committee if constitutional domain touched |
| **Evidence expectation** | Evidence index (Card 8 sources) |

---

### Classify governance risk

| Field | Detail |
|-------|--------|
| **Purpose** | Route approval |
| **Required actions** | Assign Card 3 tier; map Card 2 domain |
| **What NOT to do** | Down-classify to avoid Committee |
| **Escalation expectation** | Executive preview if CONSTITUTIONAL |
| **Evidence expectation** | Tier memo in `GOVMETA` |

---

### Committee review

| Field | Detail |
|-------|--------|
| **Purpose** | Institutional judgment |
| **Required actions** | Agenda item; quorum per 106; defer/reject documented |
| **What NOT to do** | Oral approval without minutes |
| **Escalation expectation** | MATERIAL+ required; CLARIFICATION optional skip |
| **Evidence expectation** | `GOVCOMM-*` reference |

---

### Approve / reject / defer

| Field | Detail |
|-------|--------|
| **Purpose** | Decision record |
| **Required actions** | Vote or Lead decision per tier; reject with reason |
| **What NOT to do** | “Pilot” constitutional change without vote |
| **Escalation expectation** | Defer >30d → re-triage or close |
| **Evidence expectation** | Decision + dissent if any |

---

### Controlled adoption

| Field | Detail |
|-------|--------|
| **Purpose** | Safe effective date |
| **Required actions** | Convert to `GOVCHG-*`; version bump; bulletin; training (97) |
| **What NOT to do** | Effective same day for MATERIAL+ without drill |
| **Escalation expectation** | Hold readiness promotion (94, 110) until stable |
| **Evidence expectation** | Effective date UTC; `GOVVER-*` entry |

---

### Review outcomes

| Field | Detail |
|-------|--------|
| **Purpose** | Detect regression |
| **Required actions** | 14d/30d/90d review per tier; GHS/IRS watch |
| **What NOT to do** | Close `GOVCHG` before review window |
| **Escalation expectation** | Rollback triggers (98 Card 5) |
| **Evidence expectation** | Before/after KPI snapshot |

---

### Preserve lessons learned

| Field | Detail |
|-------|--------|
| **Purpose** | Institutional memory |
| **Required actions** | Archive in 107 index; feed 111 if succession-relevant |
| **What NOT to do** | Delete failed proposal records |
| **Escalation expectation** | Committee annual meta-governance review |
| **Evidence expectation** | Lesson memo linked to `GOVMETA`/`GOVCHG` |

# Card 5 — Governance Drift & Bureaucracy Control Model

| Risk | Why dangerous | Failure consequence | Escalation | Corrective expectation |
|------|---------------|---------------------|------------|------------------------|
| **Governance drift** | Written vs practiced diverge | CLPR breach | Committee **10bd** | Revert to effective version; OCR |
| **Bureaucracy creep** | Process replaces judgment | Slow escalation | Executive review | Sunset redundant steps quarterly |
| **Safeguard dilution** | “Temporary” relaxations stick | Capital exposure | Immediate Critical | Mandatory rollback (98) |
| **Governance over-complexity** | Manuals unread | Operator error | Lead | Clarify or consolidate via 98 only |
| **Approval inflation** | Everything needs Committee | Bottleneck | Committee | Tier audit; restore Lead authority for LOW |
| **Process bloat** | Forms without decisions | Audit noise | Lead | One record per decision rule |
| **Undocumented governance evolution** | Shadow policy | Diligence fail | Audit | All changes via `GOVCHG` register |

**Lean rule:** New governance artifact must **retire or subsume** an obsolete artifact, or justify net addition in `GOVMETA`.

**Annual bureaucracy review:** Committee questions every MATERIAL+ process added in prior 12m—**retain, simplify, or sunset**.

# Card 6 — Constitutional Evolution Framework

Constitutional evolution implements [Step 98 Card 6](./Triton_Governance_Change_Management_Framework.md) under meta-governance discipline.

| Change type | When permitted | Who reviews | Who approves | Evidence required | Rollback | Stability expectation |
|-------------|----------------|-------------|--------------|-------------------|----------|----------------------|
| **Safeguard strengthening** | Incident, audit, near-miss | Full Committee | Committee + Exec if new Hard Halt class | `INC-*`/audit pack | Pre-published | 30d elevated monitoring |
| **Escalation redesign** | SLA trend, confusion | Risk Lead + Senior Op | Committee; Exec if SLA lengthen | 90d ESC data | Mandatory if drill fail | No loosen under active L3+ |
| **Authority boundary changes** | SoD gap, 93 audit | Committee | Committee + Exec if Exec tier touched | Matrix diff | Mandatory | Re-cert affected roles (97) |
| **Readiness framework updates** | IRS miscalibration | Lead + Committee | Committee; Exec if lowers bar | 110 history | Mandatory if cert dispute | No promotion during window |
| **Crisis framework revisions** | 108 post-crisis | Committee | Committee + Exec | `GOVCRISIS-*` review | Mandatory | War game within 90d (109) |
| **Succession framework updates** | 111 transition lesson | Lead + Committee | Committee | `GOVSUCC-*` | Standard 98 | Annual tabletop unchanged |

**Non-negotiable (Step 98):** Capital Preservation Doctrine; documentation ≠ runtime auth; Hard Halt; dual approval; no unauthorized governance JSON mutation; Executive+Committee Hard lift.

**Stability preservation:** During constitutional change window, **default stricter** interpretation of old and new text until effective date + drill pass.

# Card 7 — Meta-Governance Failure & Recovery Playbook

---

### Governance regression

| Field | Detail |
|-------|--------|
| **What happened** | GHS/IRS/maturity drops after change or neglect |
| **Immediate containment** | Suspend readiness promotion; increase monitoring (99) |
| **Escalation** | Committee **5bd** |
| **Evidence** | Before/after KPI; change log |
| **Recovery** | Rollback or remedial `GOVCHG`; 60d stable |
| **Failure signal** | Repeat regression same quarter |

---

### Failed governance change

| Field | Detail |
|-------|--------|
| **What happened** | Drill fail, operator confusion incident, adverse audit |
| **Immediate containment** | Revert to prior `GOVVER`; bulletin |
| **Escalation** | Per 98 rollback tier |
| **Evidence** | Rollback record linked to `GOVCHG` |
| **Recovery** | New `GOVMETA` if retry; else reject |
| **Failure signal** | Retry without new evidence |

---

### Constitutional instability

| Field | Detail |
|-------|--------|
| **What happened** | Conflicting safeguard interpretation; lift disputes |
| **Immediate containment** | Hard Halt posture; no oral override |
| **Escalation** | Executive + Committee emergency |
| **Evidence** | CLPR log; minutes |
| **Recovery** | Clarifying CONSTITUTIONAL change or rollback |
| **Failure signal** | Two constitutional emergencies same year |

---

### Approval-chain inflation

| Field | Detail |
|-------|--------|

| **Immediate containment** | Lead re-tier per Card 3 |
| **Escalation** | Committee process review |
| **Evidence** | Approval latency metrics |
| **Recovery** | Published tier guide; quarterly audit |
| **Failure signal** | SLA miss due to approval queue |

---

### Governance fragmentation

| Field | Detail |
|-------|--------|
| **What happened** | Shadow wikis; conflicting Steps |

| **Escalation** | Lead **48h**; Audit if external |
| **Evidence** | Version register vs copies |

---

### Conflicting governance assumptions

| Field | Detail |
|-------|--------|

| **Evidence** | Conflict memo |

| **Failure signal** | Repeat conflict same pair |

### Uncontrolled process growth

| Field | Detail |
|-------|--------|
| **What happened** | New checklists/forms without retirement |
| **Immediate containment** | Moratorium on new artifacts |
| **Escalation** | Committee bureaucracy review |

# Card 8 — Governance Learning & Institutional Adaptation Model

| Learning source | Why it matters | Failure consequence | Escalation | Learning expectation |
|-----------------|----------------|---------------------|------------|---------------------|
| **Crisis lessons** | Live stress truth | Repeat crisis class | Committee | `GOVCRISIS` → `GOVMETA` within post-SLA |
| **Audit findings** | External discipline | Adverse opinion | Committee **5bd** | Remediation or documented accept |
| **War-game outcomes** | Cheap failure | Unprepared live crisis | Committee if Critical fail | 109 scenario update annual |
| **Readiness failures** | IRS honesty | False confidence | Committee | Gate fix before re-cert |
| **Succession lessons** | Continuity | Post-handoff regression | Lead | 111 playbook update |
| **Escalation weaknesses** | Chain integrity | SLA breach | Lead | 90/93 change proposal only via 98 |
| **Governance near-failures** | Humility | Hidden risk | Lead | Near-miss log; no shame delete |

**Adaptation rule:** Learning becomes **either** `GOVMETA` (proposed) **or** archived lesson—never oral-only “we fixed it.”

**Deferral discipline:** Rejected proposals remain archived with reason to prevent re-litigation without new evidence.
