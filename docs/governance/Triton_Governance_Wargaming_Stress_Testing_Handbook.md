## Scope disclaimer

This handbook governs **tabletop war games, governance stress tests, and resilience measurement**—rehearsal of crises **before** they occur. It does **not** authorize live trading stress, production governance mutation, automated simulation platforms, or execution path testing.

> **Simulation improves preparedness — not guaranteed real-world outcomes.**

**War-game record ID:** `GOVWAR-YYYY-MM-DD-###` — link to `GOVTEST-*` (Step 95) when drill overlap exists.

**Default rehearsal posture:** Observe-only simulation; **no** production JSON edits; **no** runtime enablement to “win” the scenario.

# Card 1 — War-Gaming Philosophy

### Purpose of governance war-gaming

War-gaming stress-tests **people, procedures, and evidence chains** under extreme but **controlled** scenarios. It exposes weak escalation, halt discipline, committee process, and recovery sequencing **before** capital is at risk and before audit or trust crises force discovery.

### Why Triton stress-tests governance before crises occur

| Risk without rehearsal | Benefit of war-gaming |
|------------------------|----------------------|
| First real crisis is the test | Team has walked the chain |
| Paper governance | Proven responses under time pressure |
| False confidence from quiet quarters | Humility when simulations fail |
| Escalation SLAs untested | SLAs validated in simulation clock |
| Committee untrained on Hard lift | Votes practiced with evidence standards |

### Core principles

| Principle | War-game meaning |
|-----------|------------------|
| **Capital Preservation Doctrine supremacy** | Simulated responses must halt/contain first |
| **Rehearse before reality** | Quarterly minimum at MATERIAL+ tier |
| **Containment-first learning** | Failed simulation is success if found early |
| **Constitutional safeguards dominate** | Highest tier tests unanimous + Executive path |
| **Escalation discipline under stress** | Compressed clocks; no skipped roles |
| **Evidence-first resilience testing** | Score on artifacts, not persuasion |
| **Institutional calm under pressure** | Facilitator enforces procedure |
| **Humility over false confidence** | Publish weaknesses and owners |

### What governance war-gaming proves

- Escalation chain reachable within simulated SLA
- Operators/Leads apply correct halt and **refuse** unauthorized lift
- Committee and Executive follow Step 106/104 boundaries under stress
- Evidence package standards are achievable in time box
- Recovery sequencing (Step 108 Card 7) is understood
- Weaknesses are logged with remediation owners before promotion/readiness

### What governance war-gaming cannot prove

- Real crisis will match scenario
- Zero loss in actual events
- Technical systems will not fail differently
- Regulatory compliance in full
- Permanent “institutional grade” status
- That passing simulation authorizes runtime or trading expansion

# Card 2 — Governance Stress Test Classification

Five levels. Higher levels require broader participation and Committee involvement.

| Level | Code | Typical frequency |
|-------|------|-------------------|
| 1 | ROUTINE SIMULATION | Weekly/monthly (Step 95 drills) |
| 2 | MATERIAL GOVERNANCE TEST | Monthly |
| 3 | CRISIS WAR GAME | Quarterly |
| 4 | CONSTITUTIONAL FAILURE TEST | Semi-annual |
| 5 | SYSTEMIC GOVERNANCE EXTREME TEST | Annual |

---

### ROUTINE SIMULATION

| Field | Detail |
|-------|--------|
| **Definition** | Single-domain drill (Step 95 Card 2)—brief mapping, one escalation ping |
| **Scenario severity** | Low; no capital boundary |
| **Escalation expectation** | Senior Operator / Lead as designed |
| **Committee involvement** | None |
| **Evidence requirement** | `GOVTEST-*` mini record |
| **Success condition** | 100% correct posture command or chain target |

---

### MATERIAL GOVERNANCE TEST

| Field | Detail |
|-------|--------|
| **Definition** | Multi-step scenario; Soft Halt; documentation under time box |
| **Scenario severity** | Medium; integrity unconfirmed |
| **Escalation expectation** | Risk Lead within simulated **4h** |
| **Committee involvement** | Observer optional |
| **Evidence requirement** | `GOVWAR-*` + partial incident template |
| **Success condition** | Containment before “resume” narrative; audit fields draftable |

---

### CRISIS WAR GAME

| Field | Detail |
|-------|--------|
| **Definition** | 60–120 min tabletop; GOVERNANCE CRISIS tier (Step 108) |
| **Scenario severity** | High; multiple KPI flags simulated |
| **Escalation expectation** | Full chain to Committee |
| **Committee involvement** | **Required** participants |
| **Evidence requirement** | Full facilitator pack; minutes |
| **Success condition** | `GOVCRISIS-*` classification correct; recovery plan drafted |

---

### CONSTITUTIONAL FAILURE TEST

| Field | Detail |
|-------|--------|
| **Definition** | CLPR breach or unauthorized override simulation |
| **Scenario severity** | Critical; safeguard tier |
| **Escalation expectation** | **15 min** Executive notify in exercise |
| **Committee involvement** | Quorum + Executive ratification exercise |
| **Evidence requirement** | Vote minutes; violation log exercise |
| **Success condition** | Hard Halt + freeze overrides; no lift without package |

---

### SYSTEMIC GOVERNANCE EXTREME TEST

| Field | Detail |
|-------|--------|
| **Definition** | Multi-playbook cascade: audit adverse + Hard Halt + trust inquiry |
| **Scenario severity** | Maximum institutional stress |
| **Escalation expectation** | Crisis cell mode (Step 108 systemic) |
| **Committee involvement** | Full Committee + Executive + Lead |
| **Evidence requirement** | End-to-end evidence index (Step 107) |
| **Success condition** | Controlled normalization plan; no false “resolved” claim |

# Card 3 — Governance War-Game Operating Model

```
Define scenario → Classify risk → Execute simulation → Observe governance response
→ Capture evidence → Committee / Executive review → Identify weaknesses
→ Improve governance readiness
```

---

### Define scenario

| Field | Detail |
|-------|--------|
| **Purpose** | Realistic, documented inject |
| **Required actions** | Written scenario; linked Steps; time box |
| **What NOT to do** | Ad lib crisis without injects |
| **Escalation expectation** | Lead approves scenario tier |
| **Evidence expectation** | Scenario doc versioned |

---

### Classify risk

| Field | Detail |
|-------|--------|
| **Purpose** | Match Card 2 tier + Step 108 crisis class |
| **Required actions** | Facilitator announces tier at start |
| **What NOT to do** | Under-classify to avoid Committee |
| **Escalation expectation** | Tier 4+ → Committee calendar hold |
| **Evidence expectation** | Tier on `GOVWAR-*` cover |

---

### Execute simulation

| Field | Detail |
|-------|--------|
| **Purpose** | Run tabletop clock |
| **Required actions** | Role players only; facilitator injects |
| **What NOT to do** | Production changes; live enablement |
| **Escalation expectation** | Real escalation if exercise reveals live gap |
| **Evidence expectation** | Clock log UTC |

---

### Observe governance response

| Field | Detail |
|-------|--------|
| **Purpose** | Score behavior vs SOP |
| **Required actions** | Scorers use Card 4 success/failure signals |
| **What NOT to do** | Coach answers mid-scenario (debrief only) |
| **Escalation expectation** | Stop exercise if real safeguard at risk |
| **Evidence expectation** | Scoresheet |

---

### Capture evidence

| Field | Detail |
|-------|--------|
| **Purpose** | Audit trail of rehearsal |
| **Required actions** | Minutes; decisions; dissent |
| **What NOT to do** | “We would have” without draft artifacts |
| **Escalation expectation** | N/A |
| **Evidence expectation** | `GOVWAR-*` complete |

---

### Committee / Executive review

| Field | Detail |
|-------|--------|
| **Purpose** | Institutional accountability |
| **Required actions** | Tier 3+: Committee debrief **10bd** |
| **What NOT to do** | Skip debrief if “passed” |
| **Escalation expectation** | Critical fail → remediation plan vote |
| **Evidence expectation** | `GOVCOMM-*` if action items constitutional |

---

### Identify weaknesses

| Field | Detail |
|-------|--------|
| **Purpose** | Honest gap list |
| **Required actions** | Ranked weaknesses; owners |
| **What NOT to do** | Blame individuals without process fix |
| **Escalation expectation** | Material gap → Step 98 change if manual gap |
| **Evidence expectation** | Weakness register |

---

### Improve governance readiness

| Field | Detail |
|-------|--------|
| **Purpose** | Close loop |
| **Required actions** | Retest; update Step 95/97/108 training |
| **What NOT to do** | Grant readiness/maturity on pass alone |
| **Escalation expectation** | Open Critical fail blocks promotion (Step 95) |
| **Evidence expectation** | Retest `GOVWAR-*` link |

# Card 6 — Governance Resilience Measurement

Resilience scored per `GOVWAR-*` (0–100 institutional exercise score)—**not** GHS. Report to quarterly validation scorecard (Step 95 §8).

| Dimension | Why measured | Failure implication | Escalation relevance | Improvement expectation |
|-----------|--------------|---------------------|----------------------|-------------------------|
| **Escalation discipline** | Chain integrity | Real incident chaos | EF flag | +10% score or retest |
| **Containment speed** | Capital protection | Harm before halt | HHF risk | Simulated halt &lt;15m |
| **Evidence completeness** | Audit defensibility | ACR gap | Audit adverse | 100% draft fields in box |
| **Constitutional compliance** | Safeguard core | CLPR breach | Critical | Zero authority fails |
| **Recovery readiness** | Normalization safe | Re-repeat crisis | Readiness revoke | Card 7 plan in 90m exercise |
| **Safeguard survival** | Non-negotiables | Drift | Committee | No bypass approved in test |
| **Governance consistency** | Same brief → same cmd | OCR drop | Training | 95% scorer agreement |

**Aggregate resilience bands:** &lt;70 = **Fragile**; 70–84 = **Developing**; 85–94 = **Strong**; 95+ = **Exercise-ready** (does not imply live crisis proof).

# Card 10 — War-Game Checklist

**Pre-exercise**

- [ ] Scenario classified (Card 2) — `GOVWAR-*` opened
- [ ] Participants rostered (roles + backups)
- [ ] Facilitator + scorers assigned
- [ ] Production mutation **prohibited** acknowledged

**During exercise**

- [ ] Crisis severity (Step 108) announced
- [ ] Escalation chain tested (inject log)
- [ ] Hard Halt behavior tested (if in scenario)
- [ ] Committee response evaluated (tier 3+)
- [ ] Executive escalation evaluated (tier 4+)
- [ ] Evidence artifacts drafted under time box

**Post-exercise (5 business days)**

- [ ] Minutes and scoresheet archived
- [ ] Weaknesses ranked with owners
- [ ] Retest date set if Material+ fail
- [ ] Readiness/maturity **not** upgraded from exercise alone
- [ ] Step 95/97/108 training updates assigned
- [ ] Committee debrief completed (tier 3+)
