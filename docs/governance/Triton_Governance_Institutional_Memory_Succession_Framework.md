# Card 1 — Institutional Memory Philosophy

### Purpose of governance continuity

Institutional memory ensures Triton governance **does not live in one person’s head**. Decisions, rationales, crises, and safeguards remain **retrievable, teachable, and auditable** across operator turnover, Lead changes, Committee recomposition, and executive succession.

### Why governance knowledge must survive individuals

| Dependency risk | Continuity outcome |
|-----------------|-------------------|
| Founder-only judgment | Committee + manuals decide |
| Operator leaves → chaos | Shadowing + cert roster |
| “We always did it this way” orally | Versioned Steps 98 |
| Crisis lessons lost | Incident archive + war games |
| Audit asks “who decided?” | `GOVCOMM-*`, `INC-*` |

### Core principles

| Principle | Continuity meaning |
|-----------|-------------------|
| **Capital Preservation Doctrine supremacy** | Succession never relaxes containment for speed |
| **Governance survives people** | Manuals and records outrank tenure |
| **Institutional memory over personality** | No undocumented heroics |
| **Continuity before convenience** | Dual coverage before single expert |
| **Constitutional safeguards dominate** | Safeguard tier unchanged by turnover |
| **Evidence-first continuity** | Handoffs are artifact-based |
| **Succession through discipline** | `GOVSUCC-*` for every material transition |
| **Humility against founder dependency** | Executive/Founder paths documented like any role |

### What institutional continuity proves

- Knowledge is **documented, versioned, and retained** per domain (Card 2)
- Succession scenarios have **defined playbooks** (Cards 3, 6, 7)
- **No single point of failure** for Lead, Committee chair, or shift coverage
- Transitions include **validation period** before authority normalization
- Lessons learned feed **98, 95, 109** improvement cycles

### What institutional continuity cannot guarantee

- Zero disruption during turnover
- Identical judgment quality day one for successors
- Retention of all employees
- Immunity from market or technical crises
- That documentation alone prevents all errors

| Scenario | Code | Definition |
|----------|------|------------|
| Planned handoff | NORMAL | Scheduled; notice ≥10 business days |

# Card 5 — Founder / Key Person Risk Model

| Risk | Why dangerous | Failure consequence | Escalation | Corrective expectation |
|------|---------------|---------------------|------------|------------------------|
| **Founder dependency** | Undocumented ratification | Constitutional single point | Committee review annual | Secondary ratifier named |
| **Governance bottlenecks** | All escalations to one Lead | SLA miss | Committee surge plan | Named delegate 48h rule |
| **Key operator dependency** | One certified operator | Shift gap | Senior Operator | ≥2 certified per pattern (97) |
| **Committee fragility** | Quorum not met | No lift vote | Interim chair rules | Alternate members list |
| **Undocumented authority assumptions** | “Founder said OK” | CLPR breach | Immediate Critical | 93 matrix only |
| **Institutional memory loss** | Retiree leaves with context | Repeat incident | `GOVSUCC` + archive | Exit interview packet mandatory |

**Institution-first rule:** If governance **requires** a specific person to function, that is a **documented failure** remediated within 30d.

# Card 6 — Succession Operating Model

```
Transition identified → Knowledge review → Evidence transfer
→ Authority transition → Governance validation → Monitoring period → Continuity confirmation
```

---

| Field | Detail |
|-------|--------|
| **Purpose** | Start clock |
| **Required actions** | Open `GOVSUCC-*`; classify Card 3 tier |
| **What NOT to do** | Silent handoff |

| **Evidence expectation** | Notice dates UTC |

---

### Knowledge review

| Field | Detail |
|-------|--------|
| **Purpose** | Map gaps |
| **Required actions** | Card 2 domain review; open incidents |
| **What NOT to do** | Assume manuals sufficient without walkthrough |
| **Escalation expectation** | Outgoing role 10bd availability (planned) |

| Field | Detail |
|-------|--------|
| **Purpose** | Artifact handoff |
| **Required actions** | Card 4 packet; path index to `data/results/` governance artifacts |

| **Escalation expectation** | Audit if retention gap |
| **Evidence expectation** | Signed transfer checklist |

---

### Authority transition

| Field | Detail |
|-------|--------|
| **Purpose** | Formal role swap |
| **Required actions** | Step 93 matrix acknowledged; certs updated (97) |
| **What NOT to do** | Incoming approves own requests |
| **Escalation expectation** | Committee ack for Lead/Exec |
| **Evidence expectation** | Role memo in `GOVSUCC` |

---

### Governance validation

| Field | Detail |
|-------|--------|
| **Purpose** | Prove successor competence |
| **Required actions** | Step 95 drill; 102/104 role playbook review |
| **What NOT to do** | Skip validation under time pressure |
| **Escalation expectation** | Failed validation → supervised period |
| **Evidence expectation** | `GOVTEST` or shadow log |

---

### Monitoring period

| Field | Detail |
|-------|--------|
| **Purpose** | Elevated watch |
| **Required actions** | 30d daily summary review (LEAD+); 14d operator |
| **What NOT to do** | Grant readiness/maturity upgrade |
| **Escalation expectation** | Regression → Card 7 |
| **Evidence expectation** | GWS log |

---

### Continuity confirmation

| Field | Detail |
|-------|--------|
| **Purpose** | Close succession |
| **Required actions** | Lead/Chair sign `GOVSUCC` closed |
| **What NOT to do** | Close with open gaps |
| **Escalation expectation** | Committee minutes if material |
| **Evidence expectation** | Continuity confirmation memo |

**Transition window rule:** No **Institutional** readiness promotion or constitutional **98** change during monitoring unless emergency.
